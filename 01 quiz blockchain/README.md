#   Blockchain Quiz Game 
###  Developed by samuele-cabras-web3 

A simple terminal-based quiz game written in **Python 3.15** that tests your knowledge of the blockchain and cryptocurrency world. Answer the questions correctly to earn virtual tokens in your wallet!

 This is one of my first projects as I learn Python, with the ultimate goal of becoming a **Blockchain Developer**.

---

##  Features

-  **Scalable Data Structure:** Questions are stored in a list of dictionaries, making it incredibly easy to add new questions in the future.
-  **Input Cleaning:** The program cleans the user's input (removing extra spaces and ignoring case sensitivity) to prevent frustrating typos.
-  **Flexible Match Logic:** It checks if the correct answer is contained within the user's response, making the verification system more natural and forgiving.
   **Real-Time Score Tracking:** Tracks the token balance in your virtual wallet and displays the final balance once the quiz is finished.

  ---

##  Technologies Used

- **Python 3.15**.
- (core concepts used: lists, dictionaries, `for` loops, functions, and `if-else` conditions).

  ---
  
 ## How to Run It

  1.  Make sure you have Python installed on your computer.
  2. Download the 'app.py' file.
  3. Open your terminal in the folder containing the file and run the following command:
     ```bash
     python app.py
     ```
